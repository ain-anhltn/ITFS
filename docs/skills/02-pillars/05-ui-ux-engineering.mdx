# UI/UX Engineering

> **Xây giao diện chuẩn. Trải nghiệm mượt. Từ implement UI đến kiến tạo design system.**

## Lộ trình học 9 giai đoạn

| #   | Giai đoạn                              | Nội dung                                                               | Trọng tâm |
| --- | -------------------------------------- | ---------------------------------------------------------------------- | --------- |
| 1   | **UI Foundations**                     | HTML semantics, CSS box model, Flexbox/Grid, UI libraries              | J1        |
| 2   | **Component Foundations**              | Components, state, responsive design, accessibility, CSR vs SSR        | J1        |
| 3   | **UI Implementation**                  | Design specs (Figma), validation, loading/error/empty states           | J2        |
| 4   | **Feature UI Ownership**               | Reusable components, complex state, UX edge cases, accessibility       | J2        |
| 5   | **UI Architecture & Performance**      | Shared libraries, SSR/SSG/ISR, Core Web Vitals                         | J3        |
| 6   | **Project Frontend Architecture**      | Conventions, design systems, design tokens, cross-browser strategy     | J3        |
| 7   | **Cross-Project Engineering Strategy** | Lựa chọn công nghệ, độ trưởng thành design system, chuẩn accessibility | M1        |
| 8   | **Frontend Governance & Standards**    | Roadmaps, governance, UI/UX standards, frontend infrastructure         | M2 – M3   |
| 9   | **Engineering Platform Vision**        | Component ecosystems, platform strategy, AI-augmented workflows        | S1 – S3   |

## Junior

### J1 · Remember

- **Giai đoạn trọng tâm:** UI Foundations, Component Foundations
- **Chủ đề cốt lõi:** HTML semantics, CSS layout, UI libraries. Components, state, responsive design, accessibility, CSR vs SSR.
- **Vì sao:** Giao diện tốt bắt đầu từ cấu trúc rõ ràng. Cấu trúc UI quyết định khả năng bảo trì.
- **Hành vi:** Nhận biết HTML semantics, CSS box model, Flexbox/Grid. Dùng UI library theo tài liệu. Implement UI từ mockup đơn giản.
- **AI:** Dùng AI sinh component. Nhận biết khi output thiếu semantic HTML hoặc accessibility.
- **Tham chiếu:** P1

### J2 · Understand

- **Giai đoạn trọng tâm:** UI Implementation, Feature UI Ownership
- **Chủ đề cốt lõi:** Design specs, validation, loading/error/empty states. Reusable components, complex state, UX issues, accessibility.
- **Vì sao:** Sản phẩm thật phải xử lý tốt edge cases. UI mở rộng được cần tinh thần ownership và thấu hiểu người dùng.
- **Hành vi:** Hiểu component architecture, state management, responsive, accessibility, CSR vs SSR.
- **AI:** Phát hiện cấu trúc component không hợp lý do AI tạo ra.
- **Tham chiếu:** P3

### J3 · Understand → Apply

- **Giai đoạn trọng tâm:** UI Architecture & Performance, Project Frontend Architecture
- **Chủ đề cốt lõi:** Shared libraries, SSR/SSG/ISR, Core Web Vitals. Conventions, design systems, tokens, cross-browser strategy.
- **Vì sao:** Tái sử dụng và hiệu năng nâng chất lượng sản phẩm. Dự án cần nền tảng frontend dùng chung.
- **Hành vi:** Implement UI từ design specs. Responsive nhất quán. Xử lý form validation, loading/error/empty states. Quan tâm UX edge cases.
- **AI:** AI sinh code nhanh, kỹ sư kiểm tra lại responsive, a11y và các trạng thái biên mà AI bỏ sót.
- **Tham chiếu:** P2

## Middle

### M1 · Apply

- **Giai đoạn trọng tâm:** Cross-Project Engineering Strategy
- **Chủ đề cốt lõi:** Lựa chọn công nghệ, độ trưởng thành design system, chuẩn accessibility.
- **Vì sao:** Tính nhất quán quan trọng trên nhiều sản phẩm.
- **Hành vi:** Own UI feature phức tạp. Xây reusable components. Accessibility đúng chuẩn. Complex state management. Chủ động báo UX issues.
- **AI:** AI sinh nhanh, kỹ sư đảm bảo phù hợp người dùng thật. Review a11y, UX và design system.
- **Tham chiếu:** V1

### M2 · Apply → Analyze

- **Giai đoạn trọng tâm:** Frontend Governance & Standards
- **Chủ đề cốt lõi:** Roadmaps, governance, UI/UX standards, infrastructure.
- **Vì sao:** Team cần chuẩn mực để duy trì chất lượng.
- **Management:** Theo dõi chất lượng UI codebase, phát hiện chỗ không nhất quán. Review component architecture.
- **Expert:** Component architecture cho quy mô lớn. SSR/SSG/ISR. Shared library. Core Web Vitals.
- **AI:** Phân tích pattern chất lượng UI do AI tạo. Phát hiện chỗ phá vỡ design system.

### M3 · Analyze

- **Giai đoạn trọng tâm:** Frontend Governance & Standards
- **Chủ đề cốt lõi:** Roadmaps, governance, UI/UX standards, infrastructure.
- **Vì sao:** Team cần chuẩn mực để duy trì chất lượng.
- **Management:** Kiến trúc frontend toàn project. Định nghĩa conventions. Giảm tech debt.
- **Expert:** Design system (tokens, primitives). Chiến lược cross-browser/device.
- **AI:** Viết design spec rõ ràng trước khi để AI sinh UI — garbage in, garbage out.

## Senior

### S1 · Analyze → Evaluate

- **Giai đoạn trọng tâm:** Engineering Platform Vision
- **Chủ đề cốt lõi:** Component ecosystems, platform strategy, AI-augmented workflows.
- **Vì sao:** Frontend trở thành năng lực của tổ chức.
- **Management:** Kiến trúc frontend trên nhiều dự án. Phê duyệt lựa chọn công nghệ UI. Thúc đẩy chuẩn mực.
- **Expert:** Độ trưởng thành của design system. Đánh giá công nghệ frontend mới.
- **AI:** Đánh giá UI do AI sinh theo chuẩn accessibility và UX best practices.

### S2 · Evaluate

- **Giai đoạn trọng tâm:** Engineering Platform Vision
- **Chủ đề cốt lõi:** Component ecosystems, platform strategy, AI-augmented workflows.
- **Vì sao:** Frontend trở thành năng lực của tổ chức.
- **Management:** Frontend standards cho department. Đầu tư hạ tầng frontend.
- **Expert:** Design system governance. Frontend roadmap. UI/UX best practices.
- **AI:** Thiết lập chuẩn phát triển UI có AI hỗ trợ ở cấp department.

### S3 · Evaluate → Create

- **Giai đoạn trọng tâm:** Engineering Platform Vision
- **Chủ đề cốt lõi:** Component ecosystems, platform strategy, AI-augmented workflows.
- **Vì sao:** Frontend trở thành năng lực của tổ chức.
- **Management:** Tầm nhìn frontend engineering. Platform strategy.
- **Expert:** Sáng tạo design system và component ecosystem. Thought leadership.
- **AI:** Kiến tạo pipeline design-to-code có AI hỗ trợ.
